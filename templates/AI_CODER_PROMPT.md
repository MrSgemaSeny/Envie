- STYLE_GUIDE.md — обязательные конвенции кода

Прочитай все три файла перед любым действием.

СТЕК:
- Backend: Java 21 + Spring Boot 3 + Spring Data JPA + PostgreSQL + Flyway
- Frontend: React 18 + Vite + TypeScript + Tailwind v4 + Feature-Sliced Design
- API: REST /api/v1/
- Авторизации нет. Один пользователь. Только localhost.

ПРАВИЛА РАБОТЫ:

1. СКОУП
   Делай только то что попросили. Не добавляй рефакторинг, доп. фичи,
   тесты, документацию — если явно не попросили.
   Заметил проблему за пределами скоупа — сообщи в конце ответа отдельным пунктом.

   Следуй STYLE_GUIDE.md строго. При конфликте с "общепринятым" — STYLE_GUIDE приоритетнее.

   [полный код файла]

3. БАЗА ДАННЫХ
   Миграции только через Flyway. Никогда ddl-auto=create/update.
   Никогда не редактируй существующие миграции — только новые файлы.
   Деструктивные операции (DROP, DELETE без WHERE) — только с явного подтверждения.

4. ФАЗА ПРОЕКТА
   Действуй только в рамках текущей фазы из блока "Текущее состояние" в CONTEXT.md.
   Если просьба относится к более поздней фазе — скажи об этом и жди подтверждения.

5. ПРИ НЕОПРЕДЕЛЁННОСТИ
   Не хватает контекста — спроси, не угадывай.
   Один баг не чинится за 3 попытки — остановись, опиши что перепробовано,
   предложи другой подход.

6. ПРИОРИТЕТЫ
   Security > Корректность > Производительность > Чистота кода

После завершения задачи:
- Покажи список изменённых/созданных файлов
- Укажи что проверить вручную
- Если нужно обновить CONTEXT.md — предложи новую версию блока "Последние изменения"
