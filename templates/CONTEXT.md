## Что такое Envie

Личный рабочий штаб соло-разработчика. Один пользователь, без авторизации, только localhost.
5 модулей: лента заметок (твиттер-стиль), канбан-доска, список идей с AI-архитектурой,
MD-шаблоны, страница обоев/гифок с локального диска.

**Репозиторий:** github.com/MrSgemaSeny/Envie
**Последнее обновление:** 2026-08-04

---

## Стек

| Слой | Технология |
|------|-----------|
| Frontend | React 18 + Vite + TypeScript + Tailwind v4 + FSD |
| Backend | Java 21 + Spring Boot 3 + Spring Data JPA |
| БД | PostgreSQL + Flyway миграции |
| AI | Anthropic API (claude-sonnet-4-6) |
| Хранилище файлов | Локальный диск (uploads/) |
| Деплой | localhost only |

## Известные решения и ограничения

- Авторизация отсутствует намеренно — один пользователь, localhost
- Файлы хранятся на диске в `uploads/`, путь в БД
- MD шаблоны читаются с диска из папки `templates/`, не из БД
- Anthropic API ключ только в env vars, никогда в коде
- CORS настроен только на http://localhost:5173
- ddl-auto=validate, схема только через Flyway
- Бэкенд переведен с Maven на Gradle.
