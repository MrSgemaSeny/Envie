# Envie

Личный рабочий штаб соло-разработчика: идеи, заметки, канбан, шаблоны и обои.

## Стек
* **Backend:** Java 21, Spring Boot 3, PostgreSQL
* **Frontend:** React 18, Vite, TypeScript, Tailwind v4

## Запуск
1. Бэкенд: `cd backend && ./gradlew bootRun`
2. Фронтенд: `cd frontend && npm run dev`
